# Project_V working instructions

## Communication

- Use Vietnamese for user-facing communication unless the user requests another language.

## Web skills

Use relevant available skills for web work in this project. Read the selected skill's SKILL.md before applying it; use the current session's skill catalog to resolve its location. Skills are agent instructions, not application dependencies.

- `impeccable`: Primary skill for UI/UX design, interface audits, responsive behavior, accessibility, typography, spacing, interaction, and visual refinement.
- `design-taste-frontend`: Apply to landing pages, portfolios, and marketing websites when relevant. Preserve existing product content and established visual identity unless a redesign is requested.
- `vercel:react-best-practices`: Apply its review checklist after editing multiple React TSX components.
- `vercel:verification`: Apply when starting a development server or investigating a broken web flow; verify the relevant user journey end to end.
- `sites:sites`: Apply when the user requests building or managing a website through Sites, following the skill's routing instructions.
- Vercel skills: Select the specific skill only when the work involves that capability, such as deployment, authentication, environment variables, storage, backend APIs, or AI integration. Do not assume this project uses Vercel.
- `imagegen`: Use when the requested interface needs generated raster assets. Prefer existing project assets where suitable.
- `computer-use:computer-use`: Use when browser interaction or visual inspection is needed and supported.

## Workflow

- Inspect the existing files, stack, project instructions, and design context before changing code.
- For a new website, establish its purpose, audience, core content, and primary user action before choosing an implementation or visual direction. Do not invent business claims.
- Select skills that fit the actual task; do not run every web skill on every change.
- Keep layouts usable on desktop and mobile, with accessible controls, keyboard focus, readable contrast, and reduced-motion support where relevant.
- Run checks appropriate to the changes and report any validation limitations accurately.
- Publishing, service provisioning, paid resources, and account changes require user authorization for the relevant action; a request to use web skills alone does not authorize those actions.
